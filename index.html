📚 სრული თეორიული მასალა

🌐 რა არის რესპონსიული ვებ დიზაინი?

რესპონსიული ვებ დიზაინი არის მიდგომა ვებ განვითარებაში, რომელიც ქმნის დინამიურ ცვლილებებს ვებსაიტის გარეგნობაში, დამოკიდებულებით მოწყობილობის ეკრანის ზომასა და ორიენტაციაზე. ძირითადი მიზანია ისეთი ვებ გვერდების შექმნა, რომლებიც ავტომატურად ამოიცნობენ მომხმარებლის ეკრანის ზომას და ორიენტაციას და შესაბამისად ცვლიან განლაგებას.

🎯 რესპონსიული დიზაინის ძირითადი პრინციპები

1. მოქნილი ბადე სისტემები (Flexible Grid Systems)

გამოიყენეთ ფარდობითი ერთეულები (პროცენტები) ფიქსირებული პიქსელების ნაცვლად

2. მოქნილი სურათები და მედია (Flexible Images and Media)

სურათები და ვიდეოები უნდა მასშტაბირდებოდეს განლაგების შესაბამისად

3. CSS Media Queries

განსხვავებული სტილების გამოყენება მოწყობილობის მახასიათებლების მიხედვით

✅ რესპონსიული დიზაინის უპირატესობები

  • გაუმჯობესებული მომხმარებლის გამოცდილება ყველა მოწყობილობაზე
  • უკეთესი SEO რანგი (Google ამაღლებს მობილურ-თავისუფალ საიტებს)
  • ეფექტიანი ღირებულება (ერთი ვებსაიტი მუშაობს ყველა მოწყობილობაზე)
  • მარტივი მოვლა-შენახვა
  • მომავლისთვის მზა დიზაინი

🎛️ CSS @media Queries

რა არის Media Queries?

Media Queries არის CSS ტექნიკა, რომელიც საშუალებას გაძლევთ განსხვავებული სტილები გამოიყენოთ სხვადასხვა მედია ტიპებისა და პირობებისთვის, როგორიცაა ეკრანის ზომა, მოწყობილობის ორიენტაცია, რეზოლუცია და სხვა.

ძირითადი სინტაქსი:

@media media-type and (condition) { /* CSS წესები */ }

ყველაზე გავრცელებული Media ტიპები:

  • screen: კომპიუტერის ეკრანები, ტაბლეტები, სმარტფონები
  • print: პრინტერები და ბეჭდვის გადახედვა
  • speech: ეკრანის წამკითხველები
  • all: ყველა მედია ტიპი (ნაგულისხმევი)

ძირითადი Media Features:

  • width / min-width / max-width: ეკრანის სიგანე
  • height / min-height / max-height: ეკრანის სიმაღლე
  • orientation: ორიენტაცია (portrait/landscape)
  • resolution: ეკრანის რეზოლუცია
  • aspect-ratio: განიერების თანაფარდობა

Mobile-First მიდგომის მაგალითი:

/* ძირითადი სტილები მობილურისთვის */
.container {
    padding: 10px;
    font-size: 14px;
}

/* ტაბლეტისთვის */
@media screen and (min-width: 768px) {
    .container {
        padding: 20px;
        font-size: 16px;
    }
}

/* დესკტოპისთვის */
@media screen and (min-width: 1024px) {
    .container {
        padding: 40px;
        font-size: 18px;
        max-width: 1200px;
        margin: 0 auto;
    }
}

🧭 რესპონსიული ნავიგაცია

რესპონსიული ნავიგაციის ძირითადი მახასიათებლები:

  • დესკტოპზე: ჰორიზონტალური მენიუ
  • მობილურზე: ჰამბურგერ მენიუ (სამ ხაზიანი ღილაკი)
  • Touch-Friendly: საკმარისი ზომის ღილაკები (მინიმუმ 44px)
  • Smooth Transitions: გლუვი ანიმაციები
  • Accessibility: კლავიატურული ნავიგაცია

📝 HTML ფორმის ელემენტები

ძირითადი Input ტიპები:

  • text: ზოგადი ტექსტური შეყვანა
  • email: ელ-ფოსტის მისამართები (ჩართული ვალიდაციით)
  • tel: ტელეფონის ნომრები
  • password: პაროლის ველები (ტექსტი ფარულია)
  • number: რიცხვითი შეყვანა
  • date: თარიღის არჩევა
  • time: დროის არჩევა
  • url: ვებსაიტის URL-ები
  • search: ძიების ველები
  • file: ფაილის ატვირთვა

მნიშვნელოვანი Attributes:

  • required: ველს სავალდებულოს ხდის
  • placeholder: ანიშნებს დახმარების ტექსტს
  • autocomplete: ჩართავს ბრაუზერის ავტოშევსებას
  • pattern: Regex ვალიდაციის ნიმუში
  • min/max: რიცხვითი შეყვანისთვის
  • maxlength: მაქსიმალური სიმბოლოების ლიმიტი

მობილურ-ანგარიშვალდებული ფორმები:

  • font-size: 16px: თავიდან აცილება iOS-ზე Zoom-ს
  • Touch Targets: მინიმუმ 44px ზომის ღილაკები
  • Proper Input Types: სწორი ვირტუალური კლავიატურისთვის
  • Clear Labels: მკაფიო და გასაგები ეტიკეტები

// რესპონსიული ნავიგაციის toggle

// ეკრანის ზომის შემოწმება
function checkScreenSize() {
    const width = window.innerWidth;

    if (width <= 480) {
        console.log('მობილური მოწყობილობა');
    } else if (width <= 768) {
        console.log('ტაბლეტი');
    } else if (width <= 1024) {
        console.log('მცირე დესკტოპი');
    } else {
        console.log('დიდი ეკრანი');
    }
}

// ეკრანის ზომის ცვლილების მოსმენა
window.addEventListener('resize', checkScreenSize);

// ფორმის ვალიდაცია
function validateForm() {
    const email = document.getElementById('email');
    const phone = document.getElementById('phone');

    // ელ-ფოსტის ვალიდაცია
    const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    if (!emailPattern.test(email.value)) {
        alert('გთხოვთ შეიყვანოთ სწორი ელ-ფოსტა');
        return false;
    }

    // ტელეფონის ვალიდაცია (ქართული ფორმატი)
    const phonePattern = /^(\+995|995)?[0-9]{9}$/;
    if (!phonePattern.test(phone.value.replace(/\s/g, ''))) {
        alert('გთხოვთ შეიყვანოთ სწორი ტელეფონის ნომერი');
        return false;
    }

    return true;
}

// Media Query-ების JavaScript-ით შემოწმება
const mediaQuery = window.matchMedia('(max-width: 768px)');

function handleTabletChange(e) {
    if (e.matches) {
        // ტაბლეტის ეკრანზე გამოსაჩენი ფუნქციონალი
        console.log('ტაბლეტის რეჟიმი აქტიურია');
    } else {
        // დესკტოპის ეკრანზე გამოსაჩენი ფუნქციონალი
        console.log('დესკტოპის რეჟიმი აქტიურია');
    }
}

mediaQuery.addListener(handleTabletChange);
handleTabletChange(mediaQuery);
